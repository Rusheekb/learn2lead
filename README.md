# Learn2Lead Tutoring Academy Landing Page

A modern, responsive landing page for Learn2Lead Tutoring Academy built with Next.js and Tailwind CSS.

## Features

- Responsive design for all devices
- Modern UI with smooth animations
- Contact form with email integration
- Testimonials section
- Services showcase
- Benefits highlight
- Mobile-friendly navigation

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- ESLint
- PostCSS
- Autoprefixer

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/learn2lead-landing.git
   cd learn2lead-landing
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env.local` file in the root directory and add your environment variables:
   ```
   NEXT_PUBLIC_SITE_URL=http://localhost:3000
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
